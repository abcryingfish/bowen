# 成长风格标准化因子实施计划

## 目标

从 `D:\database\signal_daily` 已落盘的 12 个股票成长原始因子派生成长标准化因子，不重复读取或计算财务报表源数据。

## 实现

1. 新增 `ZXW因子/股票成长标准化因子.py`，按月读取原始因子的 `merged.parquet` 与未合并 `part_*.parquet`，同键以 part 新值为准。
2. 每个交易日对完整 A 股截面做平均排名，计算 `(rank - 0.5) / N` 百分位，再做逆正态变换并裁剪到 `[-3, 3]`。
3. 用有效输入权重重归一生成规模、盈利、质量、研发四个支柱分，再生成成长风格原始得分、百分位和标准分。
4. 在主生成器原始因子落盘后执行派生计算，按月控制内存；最终统一合并 part 并校验水位。
5. 将新因子登记到前端 `factor_catalog.json`。

## 验证

- 单元测试覆盖排名、并列、缺失、最小截面、权重重归一和落盘读取去重。
- 运行相关因子测试、JSON 校验和 Python 编译检查。
- 用本地真实数据做单月只读计算冒烟测试，不改历史原始数据。
