# 低波风格评分设计

## 目标

基于已落盘的股票低波原始因子，为每个交易日、每只符合条件的沪深 A 股生成一项可日更的 `0-100` 综合评分：

- 中文名：`低波风格评分`
- 内部键：`low_volatility_style_score`
- 方向：分数越高，代表股票在当日截面中的低波特征越强

本次只生成股票级风格评分，不生成低波组合净值、风格指数或回测模型。

## 股票池与完整性

仅接受形如 `000001.SZ`、`600000.SH` 的沪深股票代码，排除 `.BJ`、`.THS`、ETF、指数及其他证券。

每个交易日先构造统一的完整数据股票池。股票必须同时具备本设计使用的七项有限数值，才参与当日任一指标的截面排名。停牌、无成交或无真实行情的股票，其低波原始因子已由上游交易日掩码置为空，因此自然退出当日评分股票池。

当日完整股票少于 `100` 只时，当日全部输出缺失。缺失值、非数值和正负无穷均不填 `0`，也不按剩余指标重分配权重。由于评分严格要求 `252日年化波动率`，新股通常需积累约 252 个交易日后才进入评分。

## 输入

综合评分使用七项原始因子：

| 风险维度 | 中文因子 | 内部键 |
|---|---|---|
| 常规波动率 | `20日年化波动率` | `annual_vol_20d` |
| 常规波动率 | `60日年化波动率_股票` | `annual_vol_60d` |
| 常规波动率 | `252日年化波动率` | `annual_vol_252d` |
| 下行波动率 | `20日下行波动率` | `downside_vol_20d` |
| 下行波动率 | `60日下行波动率` | `downside_vol_60d` |
| 回撤风险 | `60日最大回撤` | `max_drawdown_60d` |
| 日内波动 | `14日ATR波动率` | `atr_volatility_14d` |

`20/60日波动率比` 不进入综合评分。该指标衡量近期波动扩张或收缩，而非绝对波动水平；纳入后会改变纯低波风格的含义。

## 单项评分

每个交易日只在上述统一完整股票池中独立排名。并列值使用平均名次。设当日完整股票数为 `N`，某项风险指标的升序平均名次为 `rank`，则：

```text
单项低波分 = (N - rank + 0.5) / N * 100
```

因此风险值越低，单项低波分越高。评分落在 `0` 到 `100` 之间，且不直接取到端点。

现有 `60日最大回撤` 为非正数，数值越负表示回撤越深。排名前必须转换为风险幅度：

```text
回撤风险 = abs(60日最大回撤)
```

再按回撤风险升序计算单项低波分，避免把更深的负回撤错误识别为低风险。

## 四维合成

先在风险维度内部合成，再将四个维度等权汇总，避免具有多个窗口的波动率维度获得重复权重。

```text
常规波动率低波分 =
    20日年化波动率低波分  * 20%
  + 60日年化波动率低波分  * 50%
  + 252日年化波动率低波分 * 30%

下行波动率低波分 =
    20日下行波动率低波分 * 30%
  + 60日下行波动率低波分 * 70%

回撤低波分 = 60日最大回撤幅度低波分

ATR低波分 = 14日ATR波动率低波分

低波风格评分 =
    常规波动率低波分 * 25%
  + 下行波动率低波分 * 25%
  + 回撤低波分       * 25%
  + ATR低波分        * 25%
```

由此得到的七项原始指标最终有效权重为：`5%`、`12.5%`、`7.5%`、`7.5%`、`17.5%`、`25%`、`25%`。

## 模块与数据流

新增独立派生模块 `ZXW因子/股票低波风格评分.py`。模块自行维护输入映射、完整股票池、反向截面排名和合成公式，不修改或复用其他风格评分模块的业务实现，也不改变 `低波因子.py` 的八项原始因子公式。

主生成器将其注册为后写派生 bundle，建议 bundle id 使用 `stock_low_volatility_style_score`：

```text
low_volatility
  -> 保存七项来源原始因子
  -> stock_low_volatility_style_score
  -> 保存低波风格评分
  -> 现有月度合并与批次水位
```

派生模块从 `D:\database\signal_daily` 读取目标月份七个来源因子的 `merged.parquet` 和按文件名排序的 `part_*.parquet`。同一 `time + htsc_code` 重复时，后读取的 part 覆盖旧值。每次计算读取目标月份的完整沪深股票截面，不能只对待更新代码子集重新排名。

输出继续使用现有长表分区：

```text
D:\database\signal_daily\factor=低波风格评分\year=YYYY\month=MM\merged.parquet
```

字段保持 `time`、`htsc_code`、`value`。首次运行从七项来源均具备完整 252 交易日历史的首日开始回填；后续由现有缺失检测和月度增量机制每日更新。

## 因子目录

在 `因子分类/factor_catalog.json` 的现有 `low_volatility` 分组中加入 `低波风格评分`，并将其列为核心因子。原有八项明细继续保留，`20/60日波动率比` 仍可用于观察，但不属于综合分输入。

## 异常处理

- 目标月份缺少任一来源因子分区：列出缺失来源并停止该月派生，不推进批次水位。
- 来源字段缺失或无法转换为数值：明确报错，不猜测替代列。
- 单个值非有限或七项不完整：该股票当日不参与任何单项排名，综合分保持缺失。
- 当日完整股票少于 `100`：当日全部评分保持缺失。
- 重复键：按现有 `merged + part` 文件优先级保留最新值。
- 保存失败：整批派生失败，不把该批次标记为完成。

## 测试与验收

单元测试和集成测试覆盖：

1. 七项风险越低，最终低波风格评分越高。
2. 四维权重和维度内权重符合已确认公式。
3. 负的最大回撤先转换为绝对幅度，深回撤得分更低。
4. 并列值使用平均名次。
5. 七项中任一项缺失或非有限时，该股票当日整体不评分。
6. 完整股票不足 `100` 只时，当日不生成评分。
7. `.BJ`、`.THS`、ETF 和指数不进入沪深股票截面。
8. loader 能读取 `merged + part`，且最新 part 覆盖同键旧值。
9. 主生成器、派生 bundle 和 UTF-8 因子目录注册一致。
10. 真实分区抽样验证最新日期、唯一键、非空数量、取值范围和方向。
11. 相关 `ZXW因子` 测试、Python 编译和 JSON UTF-8 解析检查通过。

## 非目标

- 不生成低波组合净值、历史走势或回测模型。
- 不做行业中性化、市值中性化或流动性约束。
- 不纳入北交所、板块、指数或 ETF。
- 不使用 PCA、历史收益优化或动态权重。
- 不修改低波原始因子的计算公式。
- 不新增停牌、退市或交易状态数据源。
