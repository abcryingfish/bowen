# 同花顺一级板块深度研究 V2 设计

## 目标

以 `2026-07-18` 为分析日期，先对12个跨类型板块进行深度试跑，验证证据时间边界、六类来源覆盖、证据关联、成分股聚合和新版Parquet契约；试跑通过后，以同一逻辑重跑全部512个同花顺软件一级板块。

## 时间口径

- `analysis_date` 固定为 `2026-07-18`。
- 行情、技术、指数和成分股聚合使用截至分析日最近一个完整交易日的数据。
- 公告、新闻、研报、产业资料和资金资料只允许使用 `published_at <= 2026-07-18 23:59:59` 的内容。
- 晚于分析日的证据不得进入评分、预测、核心逻辑或风险判断；如被检索到，只记录为后续线索，不进入本次结果。
- 旧的 `analysis_date=2026-07-15` 结果保留，新结果写入独立分区，不覆盖历史版本。

## 试跑样本

12个样本必须覆盖不同适配类型：标准行业、地域组合、周期资源、产业链主题、政策驱动、技术成长、事件驱动、证券状态、样本池、风格策略和普通概念。若同一类型没有足够样本，记录实际类型分布，不伪造覆盖。

## 证据采集契约

每个板块分别检索以下六类来源：

1. 政策：政府、监管机构、正式政策文件和可核验政策原文。
2. 研报：券商或研究机构正式研报。
3. 公告：成分股公告、业绩预告、订单、回购、诉讼、问询及治理公告。
4. 新闻：财经媒体和产业媒体的板块或公司新闻。
5. 产业数据：产量、价格、出货、订单、渗透率、招标、进出口或其他可量化产业数据。
6. 资金数据：主力资金、成交额、ETF资金、融资融券、北向/机构持仓或其他可追溯资金数据。

每板块目标保留10至20条去重证据。每条证据必须记录：

```text
evidence_id
sector_code
source_type
source_tier
published_at
source
title
url
content_hash
summary
linked_dimensions
stance
evidence_quality
time_validity
```

`linked_dimensions`只能使用`policy`、`fundamental`、`capital`、`technical`、`valuation`、`risk`；`stance`使用`supporting`、`adverse`、`mixed`；`time_validity`使用`valid_as_of_date`、`post_date_excluded`。行情稿、ETF营销稿和无关公司公告不得自动标记为政策或产业证据。

证据不足、证据冲突和检索错配必须分别标记：

- `no_data`：没有找到该类别的有效资料；
- `conflicted`：存在互相矛盾的有效资料；
- `mismatch`：检索结果与板块或成分股关联不足。

## 成分股聚合

分析层强制排除北交所`.BJ`股票。每个板块保存：

- 来源成分数、沪深有效成分数、北交所排除数；
- 行情覆盖率、财务覆盖率、估值覆盖率；
- 盈利成分占比；
- 收入同比和利润同比的中位数、P25、P75；
- 龙头贡献度：按板块成交额或市值排名前10%成分的收入/利润或市值贡献；
- 业务纯度：成分公司与板块主题的直接业务关联比例；
- 缺失原因：无数据、停牌、次新、财务尚未披露或关联性无法确认。

不得把缺失值填成0、5或其他中性值。

## 适配器研究问题

评分适配器只读取唯一的`analysis_archetype`。不同类型使用不同研究问题：

- 标准行业：供需、价格、库存、盈利周期和估值分位数。
- 周期资源：商品价格、产能、库存、资本开支和周期位置。
- 地域组合：地域政策、基建/财政、行业混合度和成分纯度。
- 产业链主题：链条位置、订单传导、上下游议价权和龙头集中度。
- 政策驱动：政策强度、执行阶段、受益范围和兑现证据。
- 技术成长：产品迭代、渗透率、研发、商业化和现金消耗。
- 事件驱动：事件真实性、时间表、成功概率、失败后回撤和事件窗口。
- 公司属性：属性一致性、代表性和跨行业暴露。
- 证券状态：退市、ST、流动性、治理和合规风险。
- 样本池：样本规则、调仓频率、幸存者偏差和样本稳定性。
- 风格策略：风格暴露、因子拥挤、收益来源和回撤历史。
- 普通概念：概念映射、业务纯度、催化强度和证据稀疏度。

## 发布与重试

试跑板块只有在以下条件全部满足时才进入正式发布：

- 六类来源检索完成并记录各类别状态；
- 证据全部通过分析日期过滤；
- 至少10条有效去重证据，或明确记录不足原因并进入人工复核；
- 成分股聚合字段完整；
- 每条评分判断至少关联一条证据或一个可复算市场/财务指标；
- 北交所排除恒等式成立；
- Parquet字段、UTF-8和HTML读取测试通过。

失败板块最多重试3次。重试必须记录失败原因和尝试编号；证据不足不是程序失败，但不得伪装成完整研究。

## 输出位置

```text
D:\database\sector_information\codex_assessments\analysis_date=2026-07-18
D:\database\sector_information\evidence\analysis_date=2026-07-18
D:\database\sector_information\claim_evidence_links\analysis_date=2026-07-18
D:\database\sector_information\sector_member_aggregates\analysis_date=2026-07-18
```

旧分区不修改。每次运行生成唯一`run_id`，所有板块共享同一成分快照、分析日期和评分策略版本。

## 验收标准

试跑阶段必须输出12板块质量报告，明确每个来源类别的证据数、无数据类别、时间过滤数、成分聚合覆盖率和失败/重试状态。只有12板块全部通过后，才启动剩余500个板块。全量阶段最终必须满足：512个唯一板块、无时间穿越、所有评分可追溯、证据与成分聚合可查询、失败任务清零或明确进入人工复核队列。
