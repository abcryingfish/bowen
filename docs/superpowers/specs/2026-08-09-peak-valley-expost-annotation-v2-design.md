# 波峰波谷事后连续标注 v2 设计

## 目标与范围

本阶段只生成离线、事后计算的波峰/波谷连续标注，不生成可预测特征，不训练模型，不替换现有 `peak_valley_label`，也不改变现有全市场因子生成链路。

首个验证对象为 `300265.SZ`，使用用户提供的人工日期作为稀疏校准锚点：明确列出的正例参与对比，明确列出的“不是波峰/波谷”日期作为显式负例，未列出的日期保持未知，不当作人工负例。

## 核心输出

主输出为两个独立的连续强度序列，取值范围 `[0, 1]`：

- `peak_valley_peak_strength_ex_post`
- `peak_valley_valley_strength_ex_post`

允许同类型相邻事件，也不强制峰谷交替。`0` 只表示当前标注器给出的强度最低，不代表人工确认的负样本。

首轮模拟必须同时输出以下诊断/拆分字段，便于判断综合强度是哪一部分贡献的；它们仍属于事后标注分量，不是可预测特征：

- `peak_valley_peak_local_position`
- `peak_valley_valley_local_position`
- `peak_valley_peak_trend_turn`
- `peak_valley_valley_trend_turn`
- `peak_valley_peak_reversal_strength`
- `peak_valley_valley_reversal_strength`
- `peak_valley_peak_persistence`
- `peak_valley_valley_persistence`
- `peak_valley_peak_confirm_delay`
- `peak_valley_valley_confirm_delay`

离散 `peak_valley_label_v2` 只作为兼容性派生字段，不参与连续强度计算。

## 分量定义

### 多尺度局部位置

使用 3、5、10、20、40、60 根交易日窗口，计算当前 High/Low 在对应局部区间中的相对百分位，分别得到波峰和波谷的局部位置分量。不得使用单一窗口的绝对最高/最低布尔判断。

### 趋势转折

使用平滑价格或 EMA 的左右斜率变化衡量转折：波峰要求左侧斜率较强、右侧斜率转弱；波谷相反。该分量属于事后标注，允许使用事件日之后的数据；不得作为实时预测特征使用。

### ATR 标准化反转

在 5、10、20、40 根未来窗口内，计算波峰的方向性回撤和波谷的方向性上涨，并按事件日 ATR 标准化。使用方向性路径障碍和首次达到时间，避免只依赖单个未来最高/最低异常点。

### 反转持续性

衡量达到反转障碍后，未来窗口内价格保持在反转阈值之外的比例。波峰统计保持在下方的比例，波谷统计保持在上方的比例。

### 几何综合

各分量先统一到 `[0, 1]`，使用平滑几何平均：

```text
strength = product(component + epsilon) ** (1 / component_count)
```

首版 `epsilon = 0.02`。首版不加入 softmax 或非极大值抑制，先观察原始分数分布和人工锚点分离度。

波峰和波谷使用相同的首版窗口集合，但分数独立计算；只有在 300265 模拟验证后，才考虑波峰/波谷参数不对称。

## 确认延迟

`confirm_delay` 定义为事件日到首次达到方向性反转障碍的交易日数量。若在最大确认窗口内未达到障碍，则为缺失值。确认延迟只用于事后标注诊断，不构成实时交易信号。

## 验证方案

300265 首轮模拟必须输出逐日期对比表，至少包含：日期、人工方向、四个分量、最终峰/谷强度、确认延迟、现有 v1 结果。

评价指标：

- 人工正例在全历史中的强度排名；
- 明确负例的强度排名；
- 波峰与波谷方向分离度；
- ±1、±2、±5 个交易日容差下的命中情况；
- 强度分布、长尾和零值比例；
- 同类型相邻日期是否被保留；
- 波峰/波谷两条分数同时偏高的比例。

不使用普通 Accuracy 作为唯一指标，不把未标注日期当作负样本，也不据此训练模型。

## 兼容与安全边界

- 只新增模拟模块/输出，不修改现有 v1 标签算法；
- 不写入现有 `signal_daily` 或 `signal_daily_label` 生产分区；
- 不改变前端、回测和普通因子生成逻辑；
- 待 300265 模拟结果确认后，再决定是否扩展到多股票和生产落盘。

## 后续阶段

本规格批准后，下一步只实现 300265 离线模拟和对比报告。只有在用户确认分数形态符合预期后，才编写详细实施计划并考虑 v2 全市场落盘。
