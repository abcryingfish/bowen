# 股票流动性综合评分设计

## 目标

在现有流动性原始因子之上生成每日股票截面的 `0-100` 综合评分，供股票筛选及后续构建高、低流动性风格走势使用。

- 分数越高，表示股票流动性越好。
- 本阶段只生成股票级评分，不生成组合净值、曲线或回测模型。
- 第一版保留流动性指标天然包含的市值暴露，不做行业或市值中性化。
- 后续若需要中性版本，新增独立评分，不改变本评分的历史口径。

## 输入与输出

### 输入因子

复用现有 `D:\database\signal_daily` 中的七个流动性原始因子：

| 中文因子 | 内部键 | 方向 |
|---|---|---|
| 20日平均成交额 | `avg_trading_value_20d` | 越高越好 |
| 60日平均成交额 | `avg_trading_value_60d` | 越高越好 |
| 20日平均换手率 | `avg_turnover_20d` | 越高越好，但极端值封顶 |
| 60日平均换手率 | `avg_turnover_60d` | 越高越好，但极端值封顶 |
| 20日Amihud非流动性 | `amihud_20d` | 越低越好 |
| 20日成交额波动率 | `trading_value_volatility_20d` | 越低越好 |
| 20日零成交额占比 | `zero_trading_value_ratio_20d` | 越低越好 |

### 输出因子

| 中文名 | 内部键 | 范围 |
|---|---|---|
| 流动性综合评分 | `liquidity_composite_score` | `0-100` |

输出沿用现有分区格式：

```text
D:\database\signal_daily\factor=流动性综合评分\year=YYYY\month=MM\merged.parquet
```

主键语义保持 `htsc_code + time`，不改变现有原始因子。

## 评分方法

### 截面与基础排名

每个交易日只对代码格式为 `dddddd.SH` 或 `dddddd.SZ` 的股票进行独立截面排名：

- 非有限值转为空值。
- 缺失值保持为空，不填零。
- 并列值使用平均名次。
- 百分位采用 `(rank - 0.5) / N * 100`，避免有效股票直接落在 0 或 100。
- 当日截面有效股票少于 100 只时，当日不生成评分。

### 四个维度

1. 成交规模，权重 35%

   ```text
   成交规模分 = mean(PCT(20日平均成交额), PCT(60日平均成交额))
   ```

2. 价格冲击，权重 30%

   ```text
   价格冲击分 = 100 - PCT(20日Amihud非流动性)
   ```

3. 换手活跃度，权重 20%

   先分别计算 20 日和 60 日平均换手率的截面百分位。百分位超过 95 时按 95 计，不再因极端高换手获得额外分数，然后重新缩放到 `0-100`：

   ```text
   capped_turnover_score = min(PCT, 95) / 95 * 100
   换手活跃度分 = mean(capped_20d, capped_60d)
   ```

   极端高换手只封顶，不反向扣分。拥挤交易与流动性是不同概念，直接扣成低流动性会改变评分含义。

4. 交易连续稳定性，权重 15%

   ```text
   成交稳定分 = 100 - PCT(20日成交额波动率)
   成交连续分 = 100 - PCT(20日零成交额占比)
   交易连续稳定性分 = 两个有效且有截面差异的子项等权平均
   ```

   如果零成交占比在当日所有有效股票中为常数，则该子项没有区分能力，不参与当日维度计算，由成交稳定分承担该维度。成交额波动率同理。

### 综合评分

```text
流动性综合评分 =
    35% * 成交规模分
  + 30% * 价格冲击分
  + 20% * 换手活跃度分
  + 15% * 交易连续稳定性分
```

成交规模和价格冲击是必需维度。换手活跃度、交易连续稳定性至少有一个有效。满足门槛但某个非必需维度缺失时，在该股票的其余有效维度间按原始权重同比例重新归一；不满足门槛时该股票评分为空。

## 数据流与接入

新增独立的后写派生模块，按现有价值、成长和纯市值评分的月度 loader 模式工作：

1. 主生成器先生成并保存七个流动性原始因子。
2. 后写模块从完整月份分区读取原始因子，合并 `merged.parquet` 与按文件名排序的 `part_*.parquet`，后文件覆盖相同主键的旧值。
3. 模块按日构建完整沪深股票截面并计算综合评分。
4. 使用现有分区写入器保存 `流动性综合评分`。
5. 将新 bundle 注册到主生成器的 lookback、module 和 post-write 配置，并加入因子目录。

模块保持自包含，不引用其他评分模块的业务实现；只复用主生成器既有的注册与分区写入接口。

## 日更与历史一致性

- 综合评分的最大输入回看窗口为 60 个交易日，后写阶段按目标月份读取完整原始因子截面。
- 日更重新计算受影响月份，保证 `part_*` 增量与月度合并后结果一致。
- 同一历史输入必须得到相同评分，不使用未来日期数据。
- 原始流动性因子定义和已有数据不修改。
- 评分仅代表截面相对流动性，不直接表示可交易状态，也不替代回测中的停牌、涨跌停和成交约束。

## 异常处理

- 请求月份缺少任一必需输入因子分区时明确失败，不写入部分评分。
- 输入文件缺少 `time`、`htsc_code` 或 `value` 时明确失败。
- 重复主键按确定的文件顺序保留最后值。
- 非沪深股票代码、`.THS`、ETF、指数和北交所代码不进入评分截面。
- 常数截面不产生虚假的高低排序；非必需常数子项退出当日计算。

## 验证标准

单元测试覆盖：

- 正反方向、并列排名与输出范围。
- 四维权重和缺失维度重归一。
- 换手率 95 分位封顶。
- 常数零成交占比退出计算。
- 必需维度、最少有效维度和 100 股票截面门槛。
- 非有限值与非沪深代码过滤。
- 月度 loader 的 `merged + part_*` 覆盖顺序和缺月失败。
- 主生成器注册及 `factor_catalog.json` 契约。

真实数据验证至少检查：

- 历史起止日期、每日有效股票数、重复主键和空值比例。
- 最新截面最小值、最大值、分位数及各维度贡献。
- 综合评分与七个原始指标的 Spearman 相关性。
- 极端高换手股票不因换手率继续获得额外分数。
- 日更重复执行结果一致，且只写入目标因子分区。

## 非目标

- 不生成高、低流动性组合净值或多空收益曲线。
- 不定义调仓频率、分组比例、交易成本或回测成交规则。
- 不修改七个原始流动性因子的计算逻辑。
- 不在第一版加入行业中性、市值中性或拥挤度反向惩罚。
