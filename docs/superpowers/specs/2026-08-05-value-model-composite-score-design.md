# 价值模型综合评分设计

## 目标

在现有六个价值因子百分位之上构建单只股票的价值模型综合评分，用于后续选股、分组回测和市场风格研究。

本次只新增一个落盘因子 `价值模型综合评分`。支柱分、基础分、数据完整度和缺失扣分仅作为内部中间量，不单独输出。

本次不做行业中性化、市值中性化，也不生成市场级价值风格收益序列。

## 输入

评分读取 `D:\database\signal_daily` 中已经落盘的六个价值百分位因子：

| 支柱 | 中文因子 | 内部键 | 权重 |
|---|---|---|---:|
| 价格估值 | 盈利收益率_EY_TTM_百分位 | `earnings_yield_ttm_percentile` | 1/6 |
| 价格估值 | 账面市值比_BM_百分位 | `book_to_market_ratio_percentile` | 1/6 |
| 价格估值 | 销售收益率_SY_TTM_百分位 | `sales_yield_ttm_percentile` | 1/6 |
| 现金流估值 | 经营现金流收益率_OCFY_TTM_百分位 | `operating_cashflow_yield_ttm_percentile` | 0.15 |
| 现金流估值 | 自由现金流收益率_FCFY_TTM_百分位 | `free_cashflow_yield_ttm_percentile` | 0.15 |
| 资产负债表价值 | 净现金市值比_百分位 | `net_cash_to_market_value_percentile` | 0.20 |

六项预设权重合计为 1。输入百分位范围为 `[0, 1]`，方向均为越高越好。`NaN`、正无穷和负无穷均视为缺失，负的原始财务值已在上游百分位中保留其排序含义。

## 评分公式

对每个交易日、每只股票独立计算有效因子数量和有效权重。

有效因子少于四项时，不生成评分，输出保持缺失。四项及以上时：

```text
基础分 = Σ(有效因子百分位 × 预设权重) / Σ(有效因子预设权重) × 100
完整度 = Σ(有效因子预设权重)
缺失扣分 = 基础分 × 0.50 × (1 - 完整度)
价值模型综合评分 = 基础分 - 缺失扣分
```

最终评分限制在 `[0, 100]`。六项完整时不扣分；缺少权重越高的因子，扣分越多。扣分作用于非负基础分，避免直接缩放负标准分时反而抬高低分股票。

示例：基础分为 80 分时，缺少净现金市值比的完整度为 0.80，扣 8 分，最终评分为 72 分。

## 输出契约

仅输出一个因子：

| 中文名 | 内部键 | 范围 | 方向 |
|---|---|---|---|
| 价值模型综合评分 | `value_model_composite_score` | 0 至 100 | 越高越具价值特征 |

继续使用现有长表分区：

```text
D:\database\signal_daily\factor=价值模型综合评分\year=YYYY\month=MM\merged.parquet
```

字段保持 `time`、`htsc_code`、`value`。历史评分从 `2015-01-01` 开始；即使生成器请求更早区间，也不输出 2015 年以前的有效评分。

原有六个价值原始因子及其 18 个去极值、百分位、标准分因子不覆盖、不改名。

## 模块与生成顺序

新增独立模块 `ZXW因子/股票价值模型综合评分.py`。模块保留自己的输入映射、权重和评分公式，不引用成长或红利综合评分实现。

生成顺序为：

```text
价值原始因子
  -> 价值去极值与标准化因子
  -> 价值模型综合评分
  -> signal_daily 月度 part
  -> 现有月度合并流程生成 merged.parquet
```

综合评分作为后写派生 bundle 接入 `ZXW策略技术因子生成.py`。同一次运行中，先保存价值百分位，再读取对应月份的 `merged.parquet + part_*.parquet` 计算综合评分。输入读取始终使用完整 A 股代码，不按本次待更新股票子集重新计算。

生成器自动计划仅对缺失或落后于目标交易日的综合评分增量运行。首次生成从 `2015-01-01` 按月回补；后续只追加新日期。

## 缺失与异常处理

- 单票有效因子少于四项：综合评分缺失。
- 四项及以上：有效权重重新归一后计算基础分，再进行缺失扣分。
- 某个月缺少任一必需输入因子分区：明确列出缺失因子并停止该派生阶段，避免静默使用不完整月份。
- 输入百分位超出 `[0, 1]`：视为数据契约错误并抛出中文异常，不做静默截断。
- 重复 `time + htsc_code`：按现有约定，`merged` 后读取按文件顺序保留最新 part。
- 2015 年以前：不输出有效综合评分。

## 目录注册

在 `因子分类/factor_catalog.json` 新增独立分组：

```text
group_id: stock_value_model
group_name: 股票价值模型
core_factors: [价值模型综合评分]
children: [价值模型综合评分]
```

生成器 bundle id 使用 `stock_value_model`。内部键、目录中文名和目录注册必须一致。

## 测试与验收

单元测试覆盖：

1. 六项完整时按预设权重计算，且不扣分。
2. 缺少净现金市值比时，按 20% 缺失权重扣分。
3. 缺少单个价格估值因子时，按 1/6 缺失权重扣分。
4. 恰好四项有效时可评分，少于四项时输出缺失。
5. 缺失因子不进入基础分分母，有效权重正确重新归一。
6. 非有限值视为缺失，输入越界时明确报错。
7. 2015 年以前不生成有效评分。
8. loader 能读取 `merged + part`，最新 part 覆盖同键旧值。
9. 生成器派生顺序、目录注册和内部键一致。
10. 实际分区抽样验证评分范围、非空数量和最新日期。
11. 全部 `ZXW因子` 测试通过。

验收数据口径：2015 年以来约 98% 的股票日具备至少四个价值因子，评分应覆盖绝大多数当日行情股票；具体覆盖率以真实回补结果为准。

## 非目标

- 不输出价值支柱分、价值基础分、价值数据完整度或价值数据缺失扣分。
- 不输出价值综合百分位或价值综合标准分。
- 不生成买卖信号或市场级价值风格强度。
- 不做行业、市值或其他风险暴露中性化。
- 不修改净现金市值比的现有缺失语义。
