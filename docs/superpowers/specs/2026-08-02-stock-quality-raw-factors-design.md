# 股票质量原始因子扩展设计

## 目标

在现有 `stock_fundamental_raw` bundle 中追加七个可从本地 QMT 财务三表稳定复算的股票质量原始因子，不生成综合质量分，不做去极值、标准化或行业中性化。

| 中文因子名 | 英文字段名 | 单位 | 方向 |
|---|---|---|---|
| 总资产收益率_ROA | `return_on_assets_ttm` | 百分数 | 高好 |
| 毛利润资产比 | `gross_profit_to_assets_ttm` | 百分数 | 高好 |
| 净利润现金含量 | `operating_cashflow_to_net_profit_ttm` | 倍数 | 高好 |
| 应计利润率 | `accruals_to_assets_ttm` | 百分数 | 低好 |
| 总资产周转率 | `asset_turnover_ttm` | 倍数 | 高好 |
| ROE标准差_12季度 | `return_on_equity_std_12q` | 百分点 | 低好 |
| 销售毛利率标准差_12季度 | `sales_gross_margin_std_12q` | 百分点 | 低好 |

## 计算口径

所有指标沿用现有公告日点时状态机，只在 `announce_date` 当日及以后可见。TTM金额先将年初至报告期末累计值还原为单季度值，再汇总最近四个连续季度。

- 平均总资产：TTM结束季度与四个季度前的总资产算术平均；两端必须有限且平均值大于0。
- ROA：TTM合并净利润 / 平均总资产 * 100。
- 毛利润资产比：TTM毛利润 / 平均总资产 * 100。
- 净利润现金含量：TTM经营现金流 / TTM合并净利润；合并净利润小于等于0时为空，避免负分母造成方向反转。
- 应计利润率：`(TTM合并净利润 - TTM经营现金流) / 平均总资产 * 100`。
- 总资产周转率：TTM营业收入 / 平均总资产。
- 12季度ROE标准差：最近12个连续报告季度各自TTM ROE的总体标准差；每个TTM ROE均使用对应期初、期末归母净资产。
- 12季度毛利率标准差：最近12个连续报告季度各自TTM销售毛利率的总体标准差。

任一必需季度、时点字段或合法分母缺失时输出空值，不填0，也不跨季度空洞拼接。新报告期所需报表尚未全部公告时保留上一完整报告期值；所需报表均已公告但字段无效时清空旧值。

## 数据与范围

复用现有 `Income.revenue`、`Income.net_profit_excl_min_int_inc`、`Income.net_profit_incl_min_int_inc`、`Balance.tot_assets`、`CashFlow.net_cash_flows_oper_act` 和按收入还原的毛利润，不新增数据源或中间仓库。ROE使用归母净利润，其余涉及总资产或合并现金流的质量指标使用合并净利润。指标仍只对股票池成员输出，ETF、指数和同花顺板块不输出。

暂不实现利息保障倍数：当前本地利润表缺少稳定的独立利息费用字段，而现金流字段混合股利与利息，强行计算会污染因子含义。

## 验收

测试必须覆盖七个目录映射、标准样例公式、净利润非正时现金含量为空、连续12季度稳定性窗口、公告日前不可见，以及原有基本面因子回归。
