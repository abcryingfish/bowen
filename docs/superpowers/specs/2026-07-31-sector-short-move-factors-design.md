# 板块短期涨跌与移动强度因子设计

## 目标

在现有 `momentum_common` 因子包中新增两个板块时序因子，用于比20日标准差波动率更早识别连续上涨、连续下跌和近期移动强度抬升。

两个因子只输出全部 `.THS` 板块代码，不输出股票、ETF或其他市场代码；按板块自身历史做时序标准化，不做板块横截面标准化。

## 因子一：板块8日涨跌幅ZScore_252日

设板块日收盘价为 `P_t`，使用8日对数累计收益：

```text
move_8d_t = log(P_t / P_{t-8})
```

对每个板块独立计算252个交易日滚动 Z-score，至少需要120个有效历史值：

```text
z_move_8d_t = (move_8d_t - rolling_mean_252(move_8d))
              / rolling_std_252(move_8d)
```

结果截断到 `[-3, 3]`。正值表示近期上涨幅度高于自身历史，负值表示近期下跌幅度高于自身历史。

中文名：`板块8日涨跌幅ZScore_252日`

英文键：`sector_return_zscore_8d_252d`

## 因子二：板块EWMA_RMS移动强度ZScore_252日

先计算日对数收益：

```text
r_t = log(P_t / P_{t-1})
```

对平方收益使用半衰期5个交易日的指数加权均值，不减去收益均值：

```text
ewma_rms_t = sqrt(252 * ewm_mean(r_t ** 2, halflife=5, adjust=False))
```

对正的 `ewma_rms` 取对数，再对每个板块独立计算252个交易日滚动 Z-score，至少需要120个有效历史值，结果截断到 `[-3, 3]`。

中文名：`板块EWMA_RMS移动强度ZScore_252日`

英文键：`sector_ewma_rms_zscore_252d`

该因子无方向，只衡量最近价格移动强度是否高于自身历史。连续上涨和连续下跌都会令其上升。

## 生成与存储

- 沿用 `momentum_common` bundle，但两个新因子分别计算、分别落盘，不引用或改写现有20日波动率因子。
- 使用 Pandas 矩阵化 `shift`、`rolling` 和 `ewm`，不增加逐板块或逐日期循环。
- 两个因子声明板块专用合并策略，保留自身 `.THS` 列、暖机期 `NaN` 和行情缺口 `NaN`。
- 接入 ZXW 自动因子目录、回看配置、板块专用执行范围、批次校验和前端 `momentum_common` 分类。
- 增量查询采用420个日历日回看，与252日标准化窗口及节假日缓冲保持一致。
- 不修改现有因子的公式、名称、输出范围或缺失值处理。

## 测试与验收

- 连续上涨输入应产生正的8日涨跌幅 Z-score；连续下跌输入应产生负值。
- 相同幅度的连续上涨和连续下跌都应抬升 EWMA-RMS 强度。
- 混合股票和板块输入时，两个新因子只能包含 `.THS` 列。
- 暖机期、无波动序列、行情缺口不得产生无穷值，缺口保持 `NaN`。
- 源函数不得包含逐板块或逐日期 `for` 循环。
- 自动规划应将两个英文键限定到全部板块行情代码，并只在执行查询层回看一次。
- 前端因子接口应在“动量策略常用因子”分组返回两个新因子。
- 现有 ZXW 因子测试套件必须保持通过。
