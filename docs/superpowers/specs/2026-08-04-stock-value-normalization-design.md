# 股票价值因子去极值与标准化设计

## 目标

在不修改现有价值原始因子的前提下，新增每日横截面的价值因子派生层。每个价值原始因子分别生成去极值值、百分位和逆正态标准分，供后续筛选与价值综合模型使用。

本次不生成价值综合得分，不做行业内标准化或行业中性化。

## 输入因子

从 `D:\database\signal_daily` 已落盘的原始因子分区读取以下六项：

| 中文名 | 内部键 | 方向 |
|---|---|---|
| 盈利收益率_EY_TTM | `earnings_yield_ttm` | 越高越好 |
| 账面市值比_BM | `book_to_market_ratio` | 越高越好 |
| 销售收益率_SY_TTM | `sales_yield_ttm` | 越高越好 |
| 经营现金流收益率_OCFY_TTM | `operating_cashflow_yield_ttm` | 越高越好 |
| 自由现金流收益率_FCFY_TTM | `free_cashflow_yield_ttm` | 越高越好 |
| 净现金市值比 | `net_cash_to_market_value` | 越高越好 |

负值具有业务含义，不按缺失值或零处理。`NaN`、正无穷和负无穷视为无效值，派生结果保持缺失。

## 计算口径

所有处理均按交易日横截面独立完成，不使用未来交易日数据。

### 1. MAD 去极值

对当日有效样本计算中位数 `median` 和中位绝对偏差 `MAD`：

```text
robust_sigma = 1.4826 * MAD
lower = median - 3 * robust_sigma
upper = median + 3 * robust_sigma
winsorized = clip(raw, lower, upper)
```

若当日 `MAD = 0`，则不截断该日有效值，避免把非恒定横截面错误压缩为单一值。

当日有效 A 股数量少于 100 时，该日三个派生结果全部为缺失。股票范围沿用生成器传入的 A 股股票池，不包含 `.THS` 等非 A 股代码。

### 2. 百分位

对去极值后的有效值使用横截面平均排名处理并列值：

```text
percentile = (average_rank - 0.5) / valid_count
```

六个输入均为正向因子，因此不反转百分位。

### 3. 标准分

对百分位做标准正态分布逆函数变换：

```text
standard_score = normal_ppf(percentile)
```

结果截断至 `[-3, 3]`。该标准分与现有成长标准化因子的量纲一致，便于未来组合，但本次不进行组合。

## 输出契约

每个原始因子生成三个独立因子，共 18 个：

| 后缀 | 中文后缀 | 含义 |
|---|---|---|
| `_winsorized` | `_去极值` | MAD 截断后的原量纲值 |
| `_percentile` | `_百分位` | 当日横截面百分位 |
| `_standard_score` | `_标准分` | 百分位逆正态标准分 |

输出继续采用现有长表分区：

```text
D:\database\signal_daily\factor=<中文因子名>\year=YYYY\month=MM\merged.parquet
```

字段保持 `time`、`htsc_code`、`value`，并同步注册到 `因子分类/factor_catalog.json`。

## 组件与数据流

新增独立的价值标准化模块，内部保留自己的原始因子映射和横截面函数，不直接依赖成长标准化模块，符合当前项目对不同业务功能保持分离的约束。

```text
价值原始因子 parquet
  -> 按月读取 merged + part，后写 part 覆盖同键旧值
  -> 对齐日期和股票代码
  -> 每日 MAD 去极值
  -> 每日百分位与逆正态标准分
  -> 生成器按缺失计划选择输出
  -> signal_daily 月度分区落盘
```

生成器在原始因子保存完成后执行价值派生阶段，确保本次刚生成的原始值可被读取。派生阶段按月计算，避免一次载入全历史；仅对自动计划中缺失或过期的价值派生因子运行，保持增量更新语义。

## 异常处理

- 缺少任一必需原始因子分区时，明确列出缺失中文因子并停止该派生阶段。
- 日期区间反向、最小样本数小于 1 等配置错误直接抛出中文异常。
- 读取 `merged.parquet` 与 `part_*.parquet` 时，同一 `time + htsc_code` 保留文件顺序中最后出现的值。
- 原始负值保留；只有非有限值转换为缺失。
- 单日样本不足时不使用较小样本勉强排名，统一输出缺失。

## 测试与验证

单元测试覆盖：

1. MAD 去极值能截断上下极端值，缺失值保持缺失。
2. `MAD = 0` 时不错误压缩横截面。
3. 并列值使用平均排名，百分位与标准分计算正确。
4. 有效样本不足时三个结果均缺失。
5. 六个因子生成完整 18 项输出，负值仍按数值大小排序。
6. 原始因子 loader 能读取月度分区，且最新 part 覆盖 merged 同键值。
7. 生成器已注册价值派生阶段，前端因子目录与模块映射一致。
8. 全部 `ZXW因子` 测试通过，并以实际分区做一个月的只读加载与计算性能冒烟测试。

## 非目标

- 不覆盖或改名现有六个价值原始因子。
- 不生成价值支柱分、价值综合得分或买卖信号。
- 不做行业分类、行业内标准化或行业中性化。
- 不改变原始基本面因子的财务口径。
