# 股票成长原始因子设计

## 目标

新增独立的 `stock_growth_raw` 股票成长原始因子 bundle，输出 12 个公告日点时、可复算的成长基础因子。此次只完成代码、目录注册、测试和真实数据抽样，不执行 `D:\database\signal_daily` 历史回填。

## 因子范围

1. 营业收入同比_TTM：本期营业收入 TTM / 去年同期营业收入 TTM - 1。
2. 营业收入三年复合增长率：本期营业收入 TTM / 三年前营业收入 TTM 的三次方根 - 1。
3. 营业利润同比_TTM：本期营业利润 TTM / 去年同期营业利润 TTM - 1。
4. 扣非净利润同比_TTM：本期扣非净利润 TTM / 去年同期扣非净利润 TTM - 1。
5. 基本每股收益同比_TTM：本期基本 EPS TTM / 去年同期基本 EPS TTM - 1。
6. 经营现金流同比_TTM：本期经营现金流 TTM / 去年同期经营现金流 TTM - 1。
7. 营业收入增速变化：当前营业收入同比_TTM - 上一报告期营业收入同比_TTM。
8. 扣非净利润增速变化：当前扣非净利润同比_TTM - 上一报告期扣非净利润同比_TTM。
9. 净资产收益率同比变化：当前 ROE TTM - 去年同期 ROE TTM。
10. 销售毛利率同比变化：当前销售毛利率 TTM - 去年同期销售毛利率 TTM。
11. 研发费用同比增速_TTM：本期研发费用 TTM / 去年同期研发费用 TTM - 1。
12. 研发费用率_TTM：研发费用 TTM / 营业收入 TTM。

所有同比类因子的去年同期分母必须大于 0，否则输出缺失值。加速度因子要求当前和上一报告期同比均有效。CAGR 要求当前和三年前 TTM 均大于 0。研发费用使用 `Income.research_expenses`，表示会计口径研发费用，不扩展为资本化研发投入。

## 数据与时点

- 使用 QMT `Income`、`CashFlow`、`Balance` 和 `PershareIndex` 财报表。
- 累计季度字段先转换为单季度值，再计算 TTM，保持现有基本面因子口径。
- 财报数据以 `announce_date` 作为生效日期；同一报告期的修订披露只从新公告日开始影响因子。
- 输出仅限普通股票代码，不生成 THS 板块或指数代码。
- 研发费用率要求营业收入 TTM 大于 0；研发费用缺失时结果为缺失。
