# 具体形态因子检验设计

## 目标

让因子检验页面直接检验 `D:\\database\\signal_daily_形态` 中的每个具体形态，使用形态 `start_time` 作为事件日期；同一股票、同一天、同一形态的多条记录取最大 `value`。

## 方案

因子检验服务继续输出统一的 `htsc_code / time / value` 数据。普通因子读取 `signal_daily`，形态因子读取形态目录中的 manifest 与按月 parquet。形态因子名称带有稳定前缀并按 level 和具体形态区分，前端将其显示在“形态面”分组中。

## 统计口径

- `time` 使用 `start_time` 的自然日。
- 同一股票、日期、具体形态分组后取最大 `value`。
- 未出现该形态的股票不补零。
- 未来收益沿用现有 close-to-close 计算。
- 每个具体形态独立计算 IC、RankIC、分组收益和事件研究。

## 验证

覆盖形态因子枚举、start_time 日期转换、最大值去重、因子源路由，并运行现有因子检验测试。
