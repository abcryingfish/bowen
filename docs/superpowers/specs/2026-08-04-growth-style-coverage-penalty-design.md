# 成长风格完整度扣分评分设计

## 目标

在不强制 12 个成长原始因子全部有效的前提下，降低缺失数据和不完整支柱对成长风格评分的影响。数值表现差与数据缺失分开处理，避免对低成长数值重复扣分。

## 输入与现有输出

输入仍为 12 个成长原始因子的每日全 A 股截面标准分。保留现有 12 个因子的百分位、标准分，四个成长支柱分，以及成长风格原始得分、标准分和百分位，不改因子目录和历史原始数据。

## 支柱计算

四个支柱及基础权重保持不变：

- 规模成长：30%
- 盈利成长：35%
- 成长质量：25%
- 研发成长：10%

每个支柱使用当日该股票的有效标准分做等权平均。支柱没有任何有效输入时为缺失；只要至少一个输入有效即可生成支柱分，不再使用“至少 50% 输入有效”的硬门槛。

每个支柱同时计算完整率：

```text
支柱完整率 = 支柱有效原始因子数 / 支柱原始因子总数
```

## 综合信号

支柱参与综合信号的有效权重为：

```text
支柱有效权重 = 支柱基础权重 × 支柱完整率
```

成长风格原始得分使用有效权重重新归一：

```text
成长风格原始得分
= Σ(支柱分 × 支柱有效权重) / Σ(支柱有效权重)
```

原始得分按每日有效股票截面继续生成成长风格百分位和标准分。原始因子数值较差会自然得到较低排名，不额外重复扣分。

## 完整度与最终评分

成长数据完整度使用支柱基础权重加权：

```text
Q
= 30% × 规模完整率
+ 35% × 盈利完整率
+ 25% × 质量完整率
+ 10% × 研发完整率
```

`Q` 的内部范围为 0 到 1，对外的 `成长数据完整度` 输出为 0 到 100。

最终评分细则：

```text
成长风格基础分 = 成长风格百分位 × 100
成长数据缺失扣分 = 20 × (1 - Q)
成长风格评分 = max(0, 成长风格基础分 - 成长数据缺失扣分)
```

只有 `Q >= 0.40` 的股票生成成长风格原始得分、百分位、标准分、基础分、缺失扣分和最终评分。低于 40% 时这些综合输出保持缺失，但支柱分和完整度仍可查看。按 2026-08-03 截面测算，该门槛覆盖约 4,988 / 5,214，只占用一个综合硬门槛。

## 新增因子

- `成长数据完整度`：0 到 100
- `成长风格基础分`：0 到 100
- `成长数据缺失扣分`：0 到 20
- `成长风格评分`：0 到 100

四个新因子加入 `stock_growth_normalized` bundle，并同步加入前端“股票成长标准化与风格因子”分组。现有因子键保持不变，新因子使用独立英文键，避免影响已有调用方。

## 增量与存储

继续从 `D:\database\signal_daily` 的 12 个成长原始因子目录读取 `merged.parquet` 与 `part_*.parquet`。主生成器仍在原始因子保存后按月执行派生阶段，不访问财务源表，不重算原始成长因子。

## 异常与边界

- 原始值为 `NaN` 或正负无穷时视为缺失。
- 不使用 0 填补缺失因子或缺失支柱。
- 截面有效股票不足 100 时，截面百分位、标准分和最终评分保持缺失。
- `Q < 0.40` 时不产生综合成长评分。
- 并列值继续使用平均名次。
- 最终评分裁剪到 0 到 100。
