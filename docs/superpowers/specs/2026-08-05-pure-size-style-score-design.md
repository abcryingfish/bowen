# 纯市值风格评分设计

## 目标

基于已落盘的 `ln_自由流通市值`，为每个交易日、每只有效股票生成两项互补的纯市值风格评分：

- `大市值风格评分（纯市值）`
- `小市值风格评分（纯市值）`

本次不做行业中性化，不混入成交额、换手率、价值、成长或其他因子，也不生成组合净值。

## 输入

唯一输入为：

| 中文因子 | 内部键 | 来源 |
|---|---|---|
| `ln_自由流通市值` | `ln_free_float_market_value` | `D:\database\signal_daily` |

派生模块读取目标月份的 `merged.parquet` 和 `part_*.parquet`。同一 `time + htsc_code` 出现多次时，按现有约定保留文件顺序中最新的 part。仅接受形如 `000001.SZ`、`600000.SH` 的沪深股票代码。

输入值为 `NaN`、正负无穷或非数值时视为缺失。`ln_自由流通市值` 已由正的自由流通市值取自然对数生成，因此派生阶段不再次取对数。

## 评分公式

每个交易日独立进行股票截面排名。并列值使用平均名次，缺失值不参与排名。设当日有效股票数为 `N`，某股票的平均名次为 `rank`：

```text
大市值风格评分（纯市值） = (rank - 0.5) / N * 100
小市值风格评分（纯市值） = 100 - 大市值风格评分（纯市值）
```

由此保证：

- 两项评分范围均为 `0` 到 `100`。
- 市值越大，大市值评分越高，小市值评分越低。
- 对所有非缺失记录，两项评分之和严格等于 `100`。
- 对数变换不改变排名，但保留标准规模因子的输入语义。

当日有效股票少于 `100` 只时，两项评分均输出缺失，避免在不完整截面上产生不可比评分。

## 输出

| 中文名 | 内部键 | 方向 |
|---|---|---|
| `大市值风格评分（纯市值）` | `large_cap_style_score_pure` | 越高越偏大市值 |
| `小市值风格评分（纯市值）` | `small_cap_style_score_pure` | 越高越偏小市值 |

继续使用现有长表分区：

```text
D:\database\signal_daily\factor=<中文因子名>\year=YYYY\month=MM\merged.parquet
```

字段保持 `time`、`htsc_code`、`value`。历史起点跟随 `ln_自由流通市值` 的有效历史，当前可从 2010 年开始。

## 模块与日更

新增独立派生模块，不引用成长、红利或价值评分实现。模块自行保留输入映射、截面排名和两项评分公式。

主生成器将该模块注册为后写派生 bundle：

```text
stock_market_data
  -> 保存 ln_自由流通市值
  -> stock_size_style_pure
  -> 保存两项纯市值评分
  -> 现有月度合并与批次水位
```

bundle id 使用 `stock_size_style_pure`。首次运行按输入历史回填；后续由现有缺失检测只追加落后的日期。派生计算始终读取当月完整沪深股票截面，不按单次待更新股票子集重新排名。

## 因子目录

在 `因子分类/factor_catalog.json` 新增独立分组：

```text
group_id: stock_size_style_pure
group_name: 股票纯市值风格评分
children:
  - 大市值风格评分（纯市值）
  - 小市值风格评分（纯市值）
```

## 异常处理

- 输入月份完全缺失：列出缺失因子并停止派生，不推进水位。
- 输入值非有限：保持缺失，不用 `0` 填充。
- 当日有效股票不足 `100`：两项评分均缺失。
- 重复键：按现有 `merged + part` 文件优先级去重。
- 单项输出失败：整批派生阶段失败，不把批次水位标为完成。

## 测试与验收

单元测试覆盖：

1. 截面排名方向正确，并列值使用平均名次。
2. 缺失和非有限值不参与排名且保持缺失。
3. 有效股票不足 `100` 时不生成评分。
4. 大小市值评分逐项相加等于 `100`。
5. loader 能读取 `merged + part`，最新 part 覆盖同键旧值。
6. 非沪深股票代码不进入评分截面。
7. bundle、主生成器和前端因子目录注册一致。
8. 真实分区抽样验证范围、互补关系、非空数量和最新日期。
9. 相关 `ZXW因子` 测试和 Python 编译检查通过。

## 非目标

- 不做行业中性化或市值中性化。
- 不合并总市值、流通市值、成交额或换手率。
- 不把大、小市值两项同时加入同一个七风格总分。
- 不处理停牌、退市原因或新增交易状态因子。
- 不在本次生成风格组合净值或回测曲线。
