# 多维度分析页面设计

## 目标

新增一个暂时为空的“多维度分析”独立页面，仅通过现有 `edge-float-hud` 悬浮球菜单访问，不加入顶部导航栏。

## 方案

- 创建 `可视化/多维度分析/index.html`，使用 UTF-8 和现有可视化基础样式。
- 页面保留品牌页头、页面标题和悬浮球，主工作区暂时为空。
- 在 `可视化/shared/edge_float_nav.js` 的统一页面注册表中增加菜单项。
- 复用现有相对路径、查询参数透传和悬浮球初始化逻辑，不修改业务数据或顶部导航。

## 验证

从量化因子页面打开悬浮球，确认菜单出现“多维度分析”；点击后进入新目录页面，中文标题正常显示，且新页面仍能通过悬浮球跳转回其他页面。
