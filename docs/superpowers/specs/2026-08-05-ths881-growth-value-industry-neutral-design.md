# THS881 成长与价值行业标准化设计

## 目标

在不改变现有成长、价值原始评分的前提下，新增两个独立的 0-100 行业标准化评分：

- `成长风格综合评分(行业标准化)`
- `价值模型综合评分(行业标准化)`

行业口径只使用同花顺 `881` 行业，不使用 `882/885/886` 地域、概念和主题板块。

## 时间与行业映射

行业数据读取 `D:\database\sector_information\constituent_snapshots_eligible`。每个评分日使用不晚于当天的最近一次快照；早于首个快照的日期不生成行业标准化评分。每个快照内，`股票代码` 必须唯一对应一个 `881` 行业，冲突时直接报错并列出股票，禁止静默保留第一条。

当前首个快照日期为 `2026-07-15`。该规则避免使用当前行业标签回填历史造成未来信息。

## 成长评分

复制现有成长标准化模块所需的原始因子映射、四支柱权重、完整度门槛和缺失惩罚逻辑，形成独立模块，不引用现有成长模块的业务函数。

处理顺序：

1. 读取 12 个成长原始因子。
2. 每日按 `881` 行业分组，对每个原始因子计算平均名次百分位和逆正态标准分。
3. 行业内有效股票少于 3 只时，该行业的该子因子保持空值。
4. 按成长规模 30%、成长盈利 35%、成长质量 25%、成长研发 10% 合成原始分。
5. 原始分再次在 `881` 行业内排名为 0-100 基础分。
6. 沿用 40% 最低完整度与 50% 缺失惩罚率，得到最终评分。

## 价值评分

复制现有价值原始因子读取、价值权重、最少有效因子和缺失惩罚逻辑，形成独立模块，不引用现有价值模块的业务函数。

处理顺序：

1. 读取 EY、BM、SY、OCFY、FCFY、净现金市值比六个价值原始因子。
2. 每日按 `881` 行业计算各子因子百分位。
3. 行业内有效股票少于 3 只时，该行业的该子因子保持空值。
4. 沿用原价值模型权重合成；至少 4 个子因子有效。
5. 合成值再次在 `881` 行业内排名为 0-100 基础分。
6. 沿用 50% 缺失权重惩罚，得到最终评分。

## 输出与接入

新增 bundle：

- `stock_growth_industry_normalized`
- `stock_value_model_industry_normalized`

新增因子：

| 中文名 | 内部键 |
|---|---|
| 成长风格综合评分(行业标准化) | `growth_style_composite_score_industry_normalized` |
| 价值模型综合评分(行业标准化) | `value_model_composite_score_industry_normalized` |

两个 bundle 接入现有自动缺失计划、按月后写和稀疏保存。只保存有限评分，不落盘物理 NULL 行。因子目录同步新增两个展示项。

## 验证

- 881 快照过滤、时点选择、唯一映射和无行业股票行为。
- 行业内排名、并列值、少于 3 个有效样本行为。
- 成长四支柱、完整度和缺失惩罚。
- 价值权重、最少 4 因子和缺失惩罚。
- 原成长、价值专项测试继续通过。
- 生成器、因子目录和按月后写契约正确。
- 真实最新快照输出无重复键、无 NULL，且各行业评分中位数接近 50。
