# 黄金板块评分 HTML 展示设计

## 目标

将 2026-07-14 黄金板块评分 JSON 转为三个可直接双击打开的本地 HTML，降低阅读成本，同时保留原始数据含义。页面均为 UTF-8 单文件，不请求网络资源，不修改现有可视化业务逻辑。

## 输出文件

- `temp/黄金板块评分_A_结构化报告.html`
- `temp/黄金板块评分_B_JSON高亮.html`
- `temp/黄金板块评分_C_交互看板.html`

## 方案 A：结构化报告

采用与项目现有量化页面相近的深色工作台风格。首屏展示板块名称、日期、总评分、结论和预测区间；正文依次展示六维评分、核心逻辑、阶段判断、多空因素、关键指标、关注股票、观察信号和数据来源。桌面使用双栏，窄屏自动切换为单栏。

## 方案 B：JSON 高亮

保留 JSON 的层级和字段顺序，使用不同颜色区分键名、字符串、数字和布尔值，并提供中文字段说明索引。页面以代码阅读为主，不修改或重新解释数据。

## 方案 C：交互看板

在方案 A 的数据基础上增加轻量交互：六维评分横向条形图、多空因素切换、内容分区折叠以及数据源筛选。所有交互使用原生 JavaScript，不引入第三方库。

## 数据与边界

三个页面使用同一份内嵌数据快照，确保数值和文案一致。页面不连接行情接口、不自动更新、不提供交易建议，也不写入浏览器存储。

## 验证

- 检查三个文件均可通过本地文件路径直接打开。
- 检查 UTF-8 中文无乱码。
- 检查桌面和手机宽度下无横向溢出、遮挡或文字截断。
- 检查方案 C 的切换、折叠与筛选功能可用。
