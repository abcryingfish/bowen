# 板块峰谷机器学习实施设计

## 1. 目标与范围

首期只处理同花顺 `881/885/886` 板块日线，使用 V2 波峰、波谷事后连续强度作为监督目标。强化学习不在本期范围。

执行顺序固定为：设计、编写、运行、有效性测试、问题修正。每个阶段达到验收门槛后才进入下一阶段。

## 2. 样本与时间语义

- 样本主键：`htsc_code + time`。
- 特征时点：交易日 `t` 收盘后已知的数据。
- 目标：`t` 日对应的波峰或波谷 V2 事后连续强度。
- 执行语义：模型若用于交易，最早从 `t+1` 开盘执行。
- V2 最长使用未来 40 个交易日；所有切分边界执行 40 个交易日 purge，测试期末尾剔除未来路径不足的样本。

## 3. 评价体系

### 3.1 单因子相关性

1. 日度横截面 Spearman Rank IC：每天在全部有效板块之间计算因子排名与 label 排名的相关性。
2. 单板块时序 Spearman IC：每个板块沿时间计算因子与 label 的秩相关性。
3. Pearson IC：只作为线性关系补充，不作为主指标。
4. ICIR：`mean(IC) / std(IC)`；年度报告同时给出均值、中位数、正值比例和有效样本数。
5. 峰、谷分别计算，不用一个净值相关性替代。

### 3.2 强事件识别

- Top 10% 捕获率：预测或因子排名前 10% 中，真实 label 位于前 10% 的比例。
- Top 10% 提升倍数：捕获率除以随机基线 10%。
- 分位数组合：按预测五分位观察真实 label 均值是否单调。
- 所有分位数阈值只使用训练期拟合。

### 3.3 模型评价

- Spearman IC、Pearson IC、MAE、Huber/MSE。
- 按年度、`881/885/886`、板块历史长度分别报告。
- 与简单基准比较：上一日 label 不可作为实时特征；基准使用价格位置、20/60 日动量等可知特征。
- 采用滚动时间外验证，不采用随机 K 折。

## 4. 阶段与验收门槛

### 阶段 A：V2 label 补齐和审计

输出：板块 label 分区和覆盖审计 JSON/CSV。

验收：

- 881/885/886 三类均有数据；代码集合与 `index_data_daily` 相交覆盖率不低于 99%。
- 峰谷强度均位于 `[0,1]`，主键无重复。
- 每个代码末端最多允许因未来窗口产生的预期缺口，不允许整段异常缺失。
- 强度不是常数，峰谷相关性、零值率和分位数均可解释。

### 阶段 B：因子审计与训练面板

输出：因子审计表、入选/排除原因、训练面板 Parquet。

硬排除规则：

- 名称含 `label`、`未来`、`事后`、V2 诊断字段。
- `.backup`、临时或删除目录。
- 缺失率过高、常数、无板块覆盖。
- 明确使用未来 shift、center 窗口的因子。

首版采用配置白名单，而不是将 1200 多个目录全部入模。入选范围优先覆盖动量、波动、均线、MACD、KDJ、RSI、OBV、通道和成交量。

验收：

- 面板主键唯一；所有特征可转换为有限数值。
- 标签字段不出现在特征列。
- 训练、验证、测试的预处理统计量严格隔离。
- 输出每个因子的横截面和时序 IC，识别重复、高相关及方向不稳定因子。

### 阶段 C：监督学习基线

模型：ElasticNet 与 sklearn `HistGradientBoostingRegressor`；若环境后续安装 LightGBM，再增加 LightGBM，不替换可复现基线。

验收：

- 峰、谷分别训练和评价。
- 至少一个模型在时间外 Rank IC 或 Top 10% 提升倍数上优于简单基准。
- 分年度和板块类型结果不能只靠单一年份或单一前缀贡献。
- 若未通过，不进入深度学习，先修正因子、标签或切分。

### 阶段 D：深度学习

前提：阶段 C 通过。首选 60 日 TCN，多任务输出峰、谷强度；与树模型使用完全相同的时间外区间比较。

## 5. 数据产物

- 代码：`ZXW因子/板块峰谷机器学习/`。
- 结果：`outputs/sector_peak_valley_ml/`。
- 大型面板数据：默认写入 `D:/database/sector_peak_valley_ml/`，不写入 Git。
- 所有 JSON、CSV 和日志使用 UTF-8；CSV 默认 `utf-8-sig`，便于 Windows Excel 打开中文。

## 6. 已知风险

- V2 是事后目标，不能作为特征。
- 同一天板块之间高度相关，普通随机切分会显著高估效果。
- 大量技术因子是同源派生，单因子显著不代表增量有效。
- 886 历史普遍较短，必须单独报告，不能用全体平均掩盖。
- IC 衡量排序相关，不直接等于可交易收益；后续仍需加入收益和成本验证。
