# 板块波峰模型多空与分组测试 V1

## 1. 目的

对 Stage D 的 `blend` 预测做横截面分组和多空评价，回答两个问题：

1. 预测最高的一组，实际波峰标签是否更高；
2. 预测最高的一组与最低的一组，未来板块收益是否存在可观察的差异。

这里不重新训练模型，不使用测试集选择参数，不把结果写入普通因子链路。

## 2. 分组方式

每日按预测值横截面排名，分别切成 5 组和 10 组：

- 第 1 组：预测最低，作为空头组；
- 最高组：预测最高，作为多头组；
- 组内采用等权平均。

多空收益定义为：

```text
LS_h(t) = mean(return_h(t, 最高预测组))
         - mean(return_h(t, 最低预测组))
```

由于当前目标是“未来波峰强度”而不是“未来上涨收益”，同时报告反向组合：

```text
Reverse_LS_h(t) = mean(return_h(t, 最低预测组))
                 - mean(return_h(t, 最高预测组))
```

如果正向标签排序成立但正向收益差为负，反向组合可能更符合“波峰风险预警”的业务含义。

其中：

```text
return_h(t) = close(t+h) / close(t) - 1
```

测试未来收益使用同花顺板块日线收盘价，h 取 1、5、10、20、40 个交易日。

## 3. 标签层评价

对每个分组直接统计实际 `peak_strength_ex_post` 的均值、中位数和数量，并计算最高组减最低组的标签差异。

这一步衡量模型是否能把高峰标签排序出来，不等同于投资收益。

## 4. 收益层评价

记录：

- 多头组平均未来收益；
- 空头组平均未来收益；
- 多空平均收益差；
- 多空收益为正的交易日比例；
- 多空 Sharpe（按日度收益差计算）；
- 累计收益差和最大回撤。

h 大于 1 时，未来收益窗口相互重叠，因此结果用于预测能力比较，不能直接等同于已扣成本的实盘复利回测。

## 5. MLflow

实验名：`sector_peak_valley_lgbm_long_short_v1`

保存分组明细、长短组合指标、审计 JSON 和来源实验标签。

## 6. 后续改进

若标签多空有效但收益多空不稳定，下一步应优先改用：

- 波谷预测与波峰预测组合；
- 未来收益作为独立监督目标；
- 成交成本、换手率和非重叠持有期的真实回测。
