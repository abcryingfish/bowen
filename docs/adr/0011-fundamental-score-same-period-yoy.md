# 基本面同比必须按同报告期并满足公告时点

基本面v1使用同一证券同一报告期的TTM收入、TTM归母净利润、ROE、净利率及盈利广度。同比只能比较最新已披露报告期与上一年度相同报告期，且两边公告日期都不得晚于分析日；没有合法配对时指标缺失，不用最近一条不同报告期数据代替。

## Consequences

- 新报告集中披露时只更新最新研究批次，不重写旧评分。
- 盈利由亏转盈、由盈转亏作为状态变化保留，不能被极端增长率掩盖。
- 行业供需和政策等非结构化证据通过有限模型调整进入，不伪装成财务字段。
- 基本面指标原始值、报告期、公告日和配对关系必须可审计。
