# Forecast与Outcome分离且概率先验逐步校准

每个最新研究批次只生成5、20、60个交易日的不可变Forecast，期限到达后追加Outcome，不修改原预测。系统正式启用初期的上涨概率标记为`prior_only`并限制置信度；样本自然积累后，使用新策略版本发布校准概率和评价指标，不回填历史预测。

## Consequences

- 预测好坏可以独立统计，不会被事后改写。
- 收益区间使用当时可得的波动和状态信息，避免未来函数。
- 方向命中、区间覆盖、Brier和LogLoss都有明确到期时间。
- 低置信度评估可以不生成方向性预测，但维度和市场数据仍可保存。
