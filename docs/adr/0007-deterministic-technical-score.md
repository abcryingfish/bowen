# 技术维度采用确定性混合标准化且禁止模型调分

技术维度只评价趋势、动量、相对强弱和价格广度，单项分数由70%绝对阈值分与30%最新横截面分组成，模型调整固定为零。该方案保留跨时间可比性，又能反映当期板块间强弱，并且不需要回填历史技术评分；波动、回撤和成交资金强度分别留给风险压力与资金维度。

## Consequences

- 技术分可以从同批次市场特征和成分快照确定性重算。
- 横截面同组不足时退化为纯绝对阈值分并降低置信度。
- 基准或成分广度缺失时按覆盖规则降权，不能由模型补分。
- 所有指标原始值、标准化分和加权贡献必须逐项保存。
