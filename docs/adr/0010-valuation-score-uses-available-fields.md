# 估值v1只使用PE、PB和亏损比例

当前统一来源稳定提供 `pe_ttm`、`pb` 及盈利正负状态，PS尚未形成一致数据源，因此估值v1只使用PE_TTM吸引力50%、PB吸引力30%和亏损成分压力20%。使用流通市值加权中位数并结合最新同类横截面，避免极端值和跨行业直接比较；模型不调整估值分。

## Consequences

- 负PE不进入PE中位数，但进入亏损比例。
- PE/PB覆盖不足时估值维度可以阻断，不填中性分。
- 接入PS、EV/EBITDA或行业专用指标时必须发布新策略版本。
- 盈利增速属于基本面，不因为估值计算使用盈利正负就转移维度归属。
