# 六维评分采用规则计算与受限模型调整

六个维度先由版本化指标和证据规则确定性地产生规则分，模型负责解释并只能在策略允许的范围内调整，单维绝对调整上限不超过0.5分。模型直接给出全部数字虽然灵活，但难以复现且容易产生历史漂移；纯公式又难以表达政策和研报中的非结构化新信息，因此采用二者分层保存的混合方式。

## Consequences

- `rule_score`、`model_adjustment`和`final_score`分别保存。
- 非零调整必须引用新增有效证据并保存理由、模型和提示词版本。
- 评分策略可以对某些维度设置更低上限或禁止模型调整。
- 数据不足主要影响置信度或阻断评分，不能由模型猜测补齐。
