# 全局快照原子发布，板块研究独立重试

板块清单和全部成分快照只有整批验证成功后才切换当前版本；基于该固定快照的512个板块研究任务分别校验、发布和重试。临时失败自动进入指数退避重试队列，终止失败进入人工复核；失败板块保留上一份正式结果并明确标记过期，其他成功板块不受阻断。

## Consequences

- 成分抓取失败不会被误判为成分调出或零成分板块。
- 每个板块任务使用输入哈希构造幂等ID，重试不会重复发布。
- 全市场横向比较只使用同一批次成功结果，不混入沿用旧结果。
- 支持断点续跑和按原运行批次重新执行失败板块。
