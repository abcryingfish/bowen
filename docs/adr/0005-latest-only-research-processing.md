# 研究任务只处理最新完整数据

日常研究任务只为运行时最新完整交易日生成市场特征、评分和预测，不为系统启用前的历史日期额外回填研究结果。历史日线仍用于最新指标的滚动窗口和前端行情展示；评分历史从正式启用后逐批自然累积，从而控制计算量并避免用当前知识重写过去观点。

## Consequences

- 默认运行只产生一个 `analysis_date` 的研究结果。
- 历史日线不会被展开成逐日历史评分。
- 同一研究日期重跑产生新修订，旧记录保持不可变。
- 前端历史评分只展示实际发布过的研究批次，不插值、不伪造历史点。
