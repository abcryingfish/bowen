# 风险压力由五类可验证风险组成

风险压力按最大回撤、波动、成分集中度、可验证拥挤度和重大下行事件五类指标计算，分数越高表示越危险。Beta暂时只展示，数据质量和证据冲突只影响置信度；模型仅可依据新增重大风险证据在正负0.3分内调整，不能用来填补缺失指标。

## Consequences

- v1拥挤度只使用现有换手率数据，不声称拥有融资、ETF份额或机构持仓。
- 集中度使用满足公告时间约束的流通市值权重，覆盖不足时整项缺失。
- 重大事件按最高有效严重度评分，不按转载篇数累计。
- 风险分在综合评分中只反向一次，前端始终展示原始压力语义。
