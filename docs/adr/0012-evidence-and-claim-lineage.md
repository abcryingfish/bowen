# 证据正文去重，主张和关系单独结构化

证据元数据、去重正文、原子主张、主张与证据链接、状态事件和关系分别保存为Parquet。证据按内容哈希去重但保留不同来源观察；主张必须能够回指证据，冲突证据共存并降低置信度，不通过来源数量投票覆盖相反事实。模型每次只读取新增证据和仍有效主张的压缩增量。

## Consequences

- 研报、公告和政策正文可以复用，不会被512个板块重复存储。
- 搜索结果只能作为发现入口，不能作为最终证据来源。
- 事实主张、观点主张、预测和模型推断区分保存。
- 证据撤回、过期和主张削弱都追加事件，不删除原文或旧状态。
