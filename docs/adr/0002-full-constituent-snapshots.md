# 每次采集完整保存板块成分快照

每个成功采集批次都完整保存来源成分关系和沪深可分析关系，即使相对上次没有变化也不只保存差异。完整快照会增加可控的Parquet存储量，但能够独立复现任一研究批次、发现漏抓和来源异常，并在变化计算损坏时重新生成变化事件与观察区间。

## Consequences

- 来源快照保留北交所，可分析快照强制排除北交所及其他不合格证券。
- 成分变化和观察区间是完整快照的可重建派生数据，不是唯一事实来源。
- 同日重复成功采集分别保存，不覆盖；最新合格快照才能进入 `current`。
- 抓取不完整的批次隔离保存，不得替换最后一次正式快照。
