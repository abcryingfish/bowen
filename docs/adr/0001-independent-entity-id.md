# 研究实体使用独立永久ID

板块及未来个股统一使用系统生成的永久 `entity_id`，不把同花顺代码、名称或分类级别编码进主键。同花顺代码可改名、变更、停用或被其他数据源替代，因此只作为带有效期的来源映射；永久ID增加一次映射查询，但能够保持历史评分、成分快照、证据、预测和知识图谱关系的连续性。

## Consequences

- 板块改名或来源代码变化时沿用原 `entity_id`。
- 板块语义发生实质变化时创建新实体，并通过生命周期事件关联旧实体。
- 页面和日志同时展示规范名称、当前来源代码和内部ID，便于人工核对。
- 来源映射必须保留历史有效期，不能只保存当前代码。
