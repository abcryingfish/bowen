# 资金评分严格区分参与代理与真实资金证据

资金维度v1使用成交额、换手和量价广度评价参与方向与持续性，同时为融资余额、ETF份额和机构持仓保留20%结构权重。当前后三类数据未形成统一来源，因此只发布 `proxy_only` 资金分并限制置信度，禁止把量价代理命名为主力净流入或真实资金流。

## Consequences

- 当前代理指标可按80%有效权重重归一化生成规则分。
- 真实资金项缺失不填零或中性分，接入后通过新策略版本启用。
- 换手参与与风险拥挤度使用不同窗口和含义，并进入重叠组审查。
- 模型只有在引用带数值、日期和资金载体的真实证据时才能调整资金分。
