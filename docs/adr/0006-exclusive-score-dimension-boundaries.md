# 六维评分采用明确且互斥的指标归属

每个正式评分指标必须指定唯一 `owner_dimension`，政策、基本面、资金、技术、估值和风险压力不重复计算同一含义。波动率和最大回撤归风险压力，价格趋势和广度归技术，证据冲突与数据质量只影响置信度；这样避免同一负面信号多次扣分，也避免把“无法确认”误判为“风险更高”。

## Consequences

- 原始字段可以参与不同派生过程，但每个正式指标只能有一个评分归属。
- 高相关跨维指标必须进入重叠检查，未经说明不能同时加权。
- 板块类型适配器可以调整指标适用性和权重，不能改变六维定义。
- 页面可以跨栏目展示指标，但非归属维度中的展示权重必须为零。
