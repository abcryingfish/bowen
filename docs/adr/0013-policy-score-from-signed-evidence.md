# 政策分使用带方向的证据信号

政策维度不按新闻数量或横截面排名，而是对有效原子政策主张计算带方向的信号：政策方向决定支持或约束，权威性、执行进度和板块传导强度决定信号幅度。证据质量、时效、来源独立性和冲突用于加权与置信度；模型只能在新增证据没有被规则充分表达时受限调整。

## Consequences

- 高权威的限制政策不会因为来源权威而得到高支持分。
- 相同政策的转载不重复计分，支持和约束主张可以净额抵消。
- 只有能回指证据的主张才能进入政策分。
- 政策分历史从正式研究启用后追加，不回填旧日期。
