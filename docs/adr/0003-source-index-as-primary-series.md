# 同花顺来源指数作为板块唯一主序列

板块历史行情、市场特征和前端主图统一以同花顺原始板块指数日线为主序列。成分股合成指数可以作为独立辅助序列，但不得静默填补、覆盖或冒充来源指数；来源指数存在缺口时明确暴露质量状态，以免混合不同编制方法后产生不可解释的收益和回撤。

## Consequences

- 来源指数与合成指数使用不同 `series_id` 和 `series_type`。
- 市场特征必须记录输入 `series_id`、截止交易日和算法版本。
- 合成指数方法未确认前只预留类型，不自动生成。
- 来源指数历史较短时指标为空或降级，不借用合成指数补足窗口。
