# 统一板块研究看板设计

## 目标

建立一个 JSON 驱动的统一板块研究看板，保留“板块研究统一看板_全展开原型”的视觉风格和全展开布局。乳业作为首个真实数据验证板块，后续其他板块通过同一页面读取各自 JSON 展示。

## 访问方式

- 默认页面加载乳业：`885462.THS`。
- 支持 URL 参数：`index.html?sector=885462.THS`。
- 页面顶部提供板块选择框，选择后更新 URL 并重新加载数据。
- URL 参数优先于默认值；选择框优先使用本地板块清单中的中文名称匹配代码。
- 数据加载失败时显示错误和文件路径，不回退到静态演示数据。

## 数据流

```text
URL/选择框 -> 板块代码 -> sector_information/reports/...json
          -> 统一字段校验 -> 数据状态/日期边界校验
          -> 各栏目动态渲染 -> 缺失与未确认项显式展示
```

页面只负责读取和展示，不重新计算评分，不补造历史、不把代理指标包装为真实资金数据。

## 固定栏目

保留原型全部栏目并全部展开：总览、六维评分、当前市场状态、短中长期预测、指数历史、评分历史、成分股快照与广度、支持/风险因素、评分依据、情景推演、重点公司与观察信号、观点变化、知识主张、证据来源、数据质量、审计信息。

新增或扩展：

- 分类契约：适配类型、分类属性、置信度、复核状态、分类理由。
- 板块边界与研究问题。
- 搜索日志与证据类别状态。
- 证据去重/筛选统计。
- 成分股全量明细、财务/估值聚合、业务纯度和龙头贡献。
- 未确认事项、缺失事项、抓取失败事项和重试记录。
- 市场数据截止日、最近完整交易日和日期排除说明。

## 缺失数据规则

- 缺失字段显示“未提供”。
- 无法确认显示“无法确认”。
- 抓取失败显示“获取失败”，并显示重试状态。
- 不同状态不得合并成“暂无数据”。
- 没有历史评分批次时显示“暂无历史批次”，不绘制伪造曲线。
- 没有正式情景概率结构时显示“未提供正式情景概率”，不使用演示情景。
- 只到较早日期的行情必须显示真实截止日和与分析日的差异。

## 乳业首批映射

页面应读取 `D:/database/sector_information/reports/analysis_date=2026-07-21/885462.THS__dairy_885462_20260721_20260721T105616586779.json`，显示 35 只来源成分、34 只有效沪深成分、1 只北交所排除成分、13 条证据、10 条主张和 3 组预测。真实综合分为 5.4，六维评分和警告以 JSON 为准。

## 兼容性

渲染器按统一 JSON 契约读取字段；单个板块字段缺失不影响页面其他栏目。板块清单和 JSON 文件路径通过配置区维护，新增板块只需增加清单项和文件，不复制 HTML。

## 验证

- 用乳业 URL 参数和页面选择框分别加载成功。
- 页面不出现黄金、半导体等静态演示文本。
- 中文 UTF-8 正常显示。
- JSON 缺失字段、加载失败和无历史批次均显示明确状态。
- 页面服务地址为 `http://127.0.0.1:8086/多维度分析/index.html`。
