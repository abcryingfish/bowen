# 板块三周期六组峰谷变化模型 V1

## 1. 研究目标

使用六个因子组预测未来 V2 波峰、波谷强度相对当前的变化，不预测收益。

```text
超短：0.5*(V2[t+1]-V2[t]) + 0.3*(V2[t+2]-V2[t]) + 0.2*(V2[t+3]-V2[t])
5日：V2[t+5]-V2[t]
20日：V2[t+20]-V2[t]
```

峰和谷分别建模。V2 当日值、未来值及变化值均为 label-only 字段，禁止进入特征 X。

## 2. 六个因子组

配置文件：`ZXW因子/板块峰谷机器学习/sector_factor_groups_v1.json`。

| 组 | 特征数 | 数据口径 |
|---|---:|---|
| 技术趋势 | 19 | 板块技术状态 |
| 横盘波动 | 10 | 板块位置、波动和新高低结构 |
| 相对强弱 | 10 | 全板块/同族相对强度、排名变化、残差强度 |
| 成分股广度 | 10 | 最新成分回填历史，个股价格采用后复权 |
| 龙头影响 | 9 | 最新成分回填历史，含涨跌占比和近似涨跌停占比 |
| 热点舆情 | 10 | 2025-08以后短历史，前半段训练、后半段测试 |

技术趋势组已增加完整纯技术因子分层模型，原19因子面板继续作为兼容版本保留：

```text
427个开发期非恒定纯技术因子
→ ADX/AMA/APO/AROON/BOLL/CCI/CMO/DEMA/MACD/MFI/MOM/PPO/ROC/RSI/STOCH/ULTOSC/WILLR/WMA 共18个子组LightGBM分数
→ 同周期、同峰/谷目标的18个子组OOF日横截面排名
→ Ridge技术大组分数
```

431个已落盘纯技术因子中，3个全样本恒定、1个仅在2023年后变化但在开发期恒定，均按无信息列排除；其余因子不按单因子IC阈值删除。

成分股广度和龙头影响组使用 `2026-08-14` 最新成分快照替代历史成分，存在幸存者偏差。涨跌停占比没有历史精确停价，使用收盘封板近似并保留 `approx_` 字段名。

## 3. 标签与后复权

来源标签：

```text
peak_strength_ex_post
valley_strength_ex_post
```

个股 OHLC 使用：

```text
adjusted_price = raw_price * adj_factor_daily
```

板块 V2 来源为同花顺板块指数连续行情；板块指数不存在个股分红除权的同类复权因子。不得将个股复权因子套用到板块指数。

当前真实 V2 在交易日 t 不可获得，因为它含未来信息。它只用于离线构造 y；线上推断只使用 t 日及以前可获得的六组因子。

## 4. 模型数量

```text
6个因子组 × 3个周期 × 2个目标（峰/谷）
= 36个第一层模型
```

每个第一层模型使用 LightGBM，并输出滚动样本外预测分。第二层按“周期 + 峰/谷目标”分别训练 Ridge：

```text
同一周期、同一目标的六组 OOF 分数
→ combined_peak_change_score / combined_valley_change_score
```

第二层禁止使用第一层训练集内预测。

技术组内部另有：

```text
18个技术子组 × 3个周期 × 2个目标 = 108个技术子组模型
```

子组模型使用2019、2020、2021、2022四个扩展窗口OOF折；技术大组Ridge固定使用开发期OOF分数训练，2023年后只预测和评价。

## 5. 时间边界

现有综合 V2 最长依赖未来40个交易日。变化目标还需要读取 t+h 的 V2，因此理论最远依赖：

```text
超短：t+43
5日：t+45
20日：t+60
```

滚动训练按周期分别使用至少 `40+h` 个交易日隔离。目标生成后，每个板块尾部3、5、20行分别标记为不完整并排除训练。

热点组只使用自身有效日期，按有效交易日顺序一分为二：前半段训练，后半段测试；测试期不用于选因子、调参、早停、第二层权重或阈值。

## 6. 最终输出

每个板块、每个日期分别输出超短、5日、20日：

```text
predicted_peak_change
predicted_valley_change
peak_change_rank_pct
valley_change_rank_pct
group_contributions
```

状态层使用每个交易日的波峰排名 `P` 和波谷排名 `V`，其中高低阈值为 0.5；在两者都低时，再用 `V>P` 区分横盘方向：

| 条件 | 状态 |
|---|---|
| `P≤0.5` 且 `V>0.5` | 波谷看涨 |
| `P>0.5` 且 `V≤0.5` | 波峰看跌 |
| `P>0.5` 且 `V>0.5` | 双向高波 |
| `P≤0.5` 且 `V≤0.5` 且 `V>P` | 横盘看涨 |
| `P≤0.5` 且 `V≤0.5` 且 `V≤P` | 横盘看跌 |

状态层只对未来 V2 峰谷强度变化做形态分类，不把这些状态直接解释为收益或交易方向；最终部署输出保留五类概率，而不是只保留一个硬标签。

## 7. 可复现契约

目标生成器保存：

```text
输入面板 SHA-256
输出目标 SHA-256
目标公式与超短权重
每个目标的有效日期、覆盖率和分布
六个目标之间的 Spearman 相关矩阵
```

模型阶段还需记录配置文件哈希、成分快照哈希、时间切分、随机种子、LightGBM/Ridge参数、OOF预测和 MLflow Run。
