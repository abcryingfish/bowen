# 板块轮动页面

## 入口与职责

- 正式入口：`http://127.0.0.1:8086/板块轮动/index.html`
- 兼容入口：`../板块轮动.html`
- 前端：`index.html`、`sector_rotation.js`、`sector_rotation.css`
- 后端：`../api_server.py`、`../market_data_service.py`

页面展示同花顺指数曲线、区间收益排序、代码/名称搜索、个股所属板块过滤和板块成分明细。

## 分类

| 前缀 | 页面标签 |
|------|----------|
| `881` | 粗行业 |
| `882` | 地域 |
| `885` | 早期细分概念 |
| `886` | 后期细分概念 |

这些是当前页面展示分组，不等于永久业务分类。来源名称或分类口径变化时，应先检查本地指数清单和成分数据再改文案。

## 主要 API

- `GET /api/market/index-codes`
- `GET /api/market/index/bars`
- `GET /api/market/index/returns`
- `GET /api/market/codes/search`
- `GET /api/market/sector-memberships`
- `GET /api/market/sector-constituents`
- `GET /api/market/sector-fund-shares`

板块资金曲线按“板块全部有效成分股当日成交额 / 当日全 A 有效成交额 × 100”计算。`881/882` 成分互斥，指标称为“资金占比”；`885/886` 成分存在交叉归属，不做归一化，指标称为“资金覆盖率”，各板块数值相加允许超过 100%。停牌或成交额小于等于 0 的股票不进入分子和分母。

全部历史日期固定使用本地最新一份成分快照回算，当前快照日期为 `2026-08-14`。这使资金曲线可以覆盖前端选择的完整行情区间，但会引入历史成分回填偏差：历史时点尚未加入或已经退出板块的股票，仍按最新快照归属处理。接口通过 `component_mode=latest_snapshot_full_history` 和 `snapshot_date` 明确返回该口径。

页面按分类批量查询资金数据，避免每个板块重复扫描日线文件；20日、60日、自定义区间按相应交易日点数截取，年初至今最多返回 400 个交易日。

板块卡片仍以来源指数 K 线作为主图，资金占比或覆盖率使用独立的左侧百分比 Y 轴叠加为折线，不参与原有指数收益率排序。资金数据读取失败或快照不足时，K 线仍正常显示，并在卡片指标处提示暂无快照。

指数曲线以来源指数日线为准，不用当前成分股合成结果补写来源指数。成分弹窗中的个股收益按返回收盘价序列计算，仅用于页面区间展示。

## 修改检查

- 保持指数前缀筛选、搜索结果、收益排序和卡片懒加载状态一致。
- 自定义区间必须限制请求点数，不能一次读取全历史所有板块。
- 调整成分逻辑时检查成分快照日期，不能用当前成分解释全部历史。
- API 字段变化时同步 `sector_rotation.js` 和相关 Python/JavaScript 测试。
- 运行 `test_sector_rotation_page.js`、`test_sector_membership_service.py` 及指数行情相关测试。
