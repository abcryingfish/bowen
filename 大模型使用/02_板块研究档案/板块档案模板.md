# 板块研究档案模板

建议目录名：`{sector_code}_{sector_name}`。

每个板块目录包含：

```text
研究档案.md
有效来源.md
失败尝试.md
历史研究索引.md
```

## 研究档案

```yaml
sector_code:
sector_name:
aliases: []
analysis_archetype:
classification_facets: []
boundary:
core_business_definition:
value_chain_positions: []
known_weak_relation_members: []
standing_research_questions: []
important_industry_indicators: []
preferred_comparison_group: []
known_data_gaps: []
last_updated_at:
```

## 历史研究索引行

```text
analysis_date | run_id | snapshot_id | report_path | verdict | overall_score | major_changes | unresolved_items
```

历史结论不得覆盖，只追加新行。
