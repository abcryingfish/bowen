# 来源失败路径库

记录已经发生的错误尝试，避免新任务无理由重复消耗时间。来源状态变化时允许重新尝试，但必须说明原因。

## 字段模板

```yaml
failure_id:
source_id:
url_or_entry:
domain:
failure_type:
first_failed_at:
last_failed_at:
affected_source_types: []
retry_policy: never | conditional | later
retry_condition:
alternative_paths: []
discovered_by_run_id:
last_checked_by_run_id:
notes:
```

失败路径与来源注册表通过 `source_id` 关联。来源不存在稳定入口时也可以先记录失败路径，但后续发现稳定来源后必须回填 `source_id`。

## 已知失败模式

### FAIL_CERTIFICATE_PAGE

```yaml
failure_type: certificate_error
retry_policy: conditional
retry_condition: 网站证书恢复，或能够从权威转载核验原文
notes: 记为retrieval_failed，不得记为没有数据，也不得只凭搜索标题入证据包。
```

### FAIL_SEARCH_SNIPPET_ONLY

```yaml
failure_type: search_snippet_only
retry_policy: later
alternative_paths: [官网原文, 权威转载, 正式PDF, 公告镜像]
notes: 搜索摘要只能帮助调整查询词，不能直接形成正式主张。
```

### FAIL_UNCLEAR_INTRADAY_TIME

```yaml
failure_type: analysis_date_time_unknown
retry_policy: conditional
retry_condition: 找到精确发布时间或可证明在分析时点前公开
notes: 分析日当天但发布时间不清的内容不得进入当日评分。
```

### FAIL_BJ_MISMATCH

```yaml
failure_type: excluded_market
retry_policy: never
notes: 北交所股票及其资金、公告、行情不得进入当前沪深板块聚合；搜索到时记为mismatch。
```

### FAIL_DUPLICATE_REPRINT

```yaml
failure_type: duplicate_or_reprint
retry_policy: never
notes: 优先保留最接近原始发布者的内容，不把同稿转载计为多条独立证据。
```
